# Provenance Recoverability Gate

## Goal

Measure how much scene lineage is recoverable structurally from raw traces.

Do not attempt to prove the thesis.

## Procedure

1. Preserve source provenance and hashes.
2. Fetch/inspect `chat.jsonl` and matching score records without unnecessary image bulk.
3. Locate judge quotes deterministically.
4. Reconstruct R0-R5 using only trace-derived evidence.
5. Separate exact, strong, weak, and unknown edges.
6. Include negative controls.
7. Do not use LLM/VLM semantic inference to fill missing lineage.
8. Report unresolved cases explicitly.
9. Compare the proposed graph abstraction against AgentTrails before claiming a structural novelty.
10. Update ledgers and progress.

## Critical adversarial case

A screenshot can be genuinely captured and still be fake evidence if the displayed scene was generated by agent-authored substitute code (for example, a fake Tk/HTML/UI renderer).

Therefore:

`capture provenance != scene authenticity`

The instrument must test target-scene reachability, not merely capture mechanism.

## Stop condition

If target-vs-substitute scene lineage is usually not structurally recoverable, stop and report the boundary. Do not replace the missing evidence with an LLM judge and retain the same claim.
